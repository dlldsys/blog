## 今日要闻

### 1. xAI 发布 Grok 4.6，正式面向网页与移动端

8 月 29 日，xAI 官方宣布 Grok 4.6 正式上线，支持官网（Grok.com）、iOS 与 Android 客户端，官方推荐用于处理复杂问题、智能体（Agent）查询以及构建应用程序，网页端还提供图像生成（Imagine）功能。

来源：[InfoQ AI 快讯](https://www.infoq.cn/aibriefs)

### 2. MiniMax 发布开放权重视频生成模型 Fast H3 v1

MiniMax 推出开放权重视频生成模型 MiniMax Fast H3 v1，可在 13 秒内生成 15 秒的 768p 视频，与 NVIDIA AI Blackwell GPU 协作实现最高 14 倍加速。该模型由 MiniMax、Hao AI Lab、NVIDIA FastGen 等团队联合推出，Hao AI Lab 的 FastVideo 框架将加速方案完全开源，标志开放权重视频模型时代的重要进展。

来源：[InfoQ AI 快讯](https://www.infoq.cn/aibriefs)

### 3. Google 推出 Gemini 学生返校优惠与月度更新

Google 宣布自 2026 年 8 月 29 日起面向返校季推出学生免费订阅：符合条件的美国学生可免费获得 1 年 Google AI Pro，覆盖 140 多个国家的学生可免费获得 1 年 Google AI Plus。同时本次 Gemini Drops 月度更新涵盖学生资源、使用 Gemini 3.7 Flash 处理多步骤任务，以及通过 Gemini Live 委派待办事项等方向。

来源：[InfoQ AI 快讯](https://www.infoq.cn/aibriefs)

### 4. a16z 推出 11 亿美元 Machine Age Fund，聚焦智能基础设施

a16z 宣布推出规模达 11 亿美元的 Machine Age Fund，用于投资构建智能运行基础的创始人，涵盖芯片、内存、网络、系统软件、电力以及将 AI 带入物理世界的机器，由 Ben Horowitz、Martin Casado、Raghu Raghuram 共同领导。Casado 表示，利用编码为知识工作者构建工具是下一个前沿领域。

来源：[InfoQ AI 快讯](https://www.infoq.cn/aibriefs)

### 5. DeepSeek Harness 周涨近 7 万星，成本周涨星最快项目

据 RepoRadar 周榜数据，deepseek-ai/deepseek-harness 过去 7 天新增约 68,978 星、总星标突破 185k，稳居本周 GitHub 涨星榜首。该项目坚持"Everything is a Plugin"设计，核心保持极简、模型与工具全部作为插件接入。

## 新工具 & CLI

### Conifer 开源统一推理 SDK

Conifer 于 8 月 29 日宣布其 SDK 正式开源，作为统一推理网关支持云端或自托管模型、微调模型、用户自有 API 密钥以及本地硬件，安装即可接入多种模型，简化多模型推理集成流程。

来源：[InfoQ AI 快讯](https://www.infoq.cn/aibriefs)

### LangChain 就新版 MCP 规范支持征集反馈

LangChain 创始人 Harrison Chase 在 Twitter 发文，表示已针对最新 MCP（Model Context Protocol）规范完成适配，并公开征集社区反馈以优化支持，MCP 生态进一步走向标准化。

来源：[InfoQ AI 快讯](https://www.infoq.cn/aibriefs)

### DeepSeek Harness（dsh）— 开源 CLI 编程代理

深度求索开源的 MIT 协议 CLI 编程代理，模型适配器、工具、会话日志与 Agent 循环全部可插拔，已成为本周 GitHub 涨星最快的项目之一。

来源：[Rising Stars Weekly](https://github.com/KhangYen/rising-stars-weekly) · [DataCamp](https://www.datacamp.com/blog/best-ai-agents)

### Microsoft Agent Framework 进入 1.0 生产版本

Microsoft Agent Framework 在 .NET 与 Python 上达到 1.0 生产就绪版本，提供企业级多 Agent 编排与长期支持承诺。

来源：[Microsoft DevBlogs](https://devblogs.microsoft.com/agent-framework/microsoft-agent-framework-version-1-0/)

### Exa AI Labs 动态高亮研究预览

Exa AI Labs 发布"动态高亮"（dynamic highlights）研究预览，使用自定义模型联合扫描文档集合并过滤冗余信息，平均减少 95% 的 Token 使用。

来源：[InfoQ AI 快讯](https://www.infoq.cn/aibriefs)

## 编程方式

### OpenAI 发布《构建 AI 原生工程团队》指南

OpenAI 发布面向工程的指南，系统阐述 Coding Agents 如何改变软件开发生命周期：从计划与范围界定阶段读取需求说明、对标代码库、标记歧义并拆解子任务，到自动追踪代码路径，显著缩短原本需要数小时乃至数天的人工排查。

来源：[OpenAI 官方 PDF](https://cdn.openai.com/business-guides-and-resources/building-an-ai-native-engineering-team.pdf)

### 斯坦福 DSPy.Flex()：优化整个 Python 模块

斯坦福 NLP 实验室发布 DSpy.Flex() 方法，可优化整个 Python 模块而不仅是提示词与参数，在测试中相比 DSpy.Predict 实现更高准确率、同时减少 LLM 调用次数，加速了 DSPy 的自动化优化能力。

来源：[InfoQ AI 快讯](https://www.infoq.cn/aibriefs)

### Agentic Coding 进入方法论化阶段

SonarSource 的《Agentic Coding 终极指南》将"AI 智能体自主规划、编写、测试并迭代代码"定义为一种完整的方法论；国内社区也总结出从需求定义、Issue 创建到 AI 实现、代码审查、合并上线的标准化流水线，强调先规划后实现、验证先行。

来源：[SonarSource 指南](https://www.sonarsource.com/resources/library/agentic-coding/) · [六阶段自动化开发流水线](https://blog.csdn.net/u013970991/article/details/161518043)

### Agent 技能成为新的"包管理器"层

本周涨星榜前列的 deepseek-harness、skills、superpowers 等仍是"技能/可插拔"生态项目，开发者正把"技能"定义成可安装、可分享、可组合的包，AI 编程 Agent 的生态分发层持续成型。

来源：[开源早知道](https://blog.csdn.net/xiaoquqi) · [GitHub Ranking AI](https://github.com/yuxiaopeng/github-ranking-ai)

## 总结

今天的 AI 趋势集中于"模型发布与生态加速"：xAI 闷声推出 Grok 4.6、MiniMax 把开放权重视频模型推进到"13 秒生成 15 秒视频"的实时档位，而 DeepSeek Harness 一周狂揽近 7 万星——头部厂商一边在基础模型上密集迭代，一边通过开源 Agent 框架与可插拔"技能"抢夺开发者分发入口，AI 开发正在从"模型军备竞赛"走向"生态与工程效率之争"。
