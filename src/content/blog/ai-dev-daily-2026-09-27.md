## 编程方式

AI 编程正在分化出「编辑器内」「终端内」「CI 流水线内」三种并行形态：一方面，Anthropic 的 Claude Code、Google 的 Gemini CLI、GitHub 的 Copilot CLI 都把 Agent 直接搬进终端，让自然语言驱动日常 git/测试/重构流程；另一方面，Cline CLI 等把 Agent 引入脚本、cron 与 CI，实现"自动化里再套一层 AI 自动化"。与之呼应，模型侧也全面 Agent 化——阶跃 Step 5、智谱 GLM-5.3、OpenAI GPT-6 Sol 都面向复杂 Agent 工作流设计，单任务成本大幅下降。开发者工作流正从"人写代码、AI 补全"转向"AI Agent 规划执行、人定义需求并审查产出"，并进一步迈向"AI 在流水线中自主运转"的阶段。

## 总结

今日趋势一句话：AI 竞争进一步「卷向价格与落地」——国内 DeepSeek 涨价达标、阿里语音大降价形成两极，阶跃/智谱/千问以开源 Agent 基座争夺开发者；国外 OpenAI、Anthropic、Google、Meta 在旗舰模型与实时语音/虚拟化身上正面交锋；而编程方式上，Agent 正从编辑器走向终端与 CI 流水线，AI 编程彻底进入"多智能体 + 自然语言 + 自动化"并行交付的新阶段。
