## 今日要闻

### 1. 中国移动与智谱签署全面合作协议，GLM 接入移动云 MaaS

智谱 GLM 系列模型将接入中国移动移动云 MaaS 平台，合作覆盖国产算力供给、模型服务到商业化分发的完整链条，国产大模型与运营商算力绑定进一步加深。

来源：[今日AI行业热点速览](https://m.sohu.com/a/1098939053_122550976/)

### 2. 阿里千问 Qwen4 系列跑分泄露，或被曝超越 Claude Opus 5.5

官方连续预热后，Qwen4 在部分基准测试中的成绩被曝超越 Anthropic Opus 5.5。若属实，将成为国产大模型首次在综合跑分上登顶全球第一梯队。

来源：[今日AI行业热点速览](https://m.sohu.com/a/1098939053_122550976/)

### 3. DeepSeek-V4.1-Flash 实现推理过程"自我改写"

DeepSeek V4.1 Flash 可读取自身最深 7 层内部激活，用 Python 代码在推理中监测并回滚跑偏的思路，在 AIME 与 HMMT 数学竞赛上准确率提升约 7 个百分点，背后是 DoubleAI 提出的"机制干预"（mechanistic intervention）新范式。

来源：[今日AI行业热点速览](https://m.sohu.com/a/1098939053_122550976/)

### 4. OpenAI 再融 110 亿美元，估值达 1.25 万亿美元

首笔资金已到账，剩余额度预计数周内完成。私募资本继续主导前沿模型定价，OpenAI 在账面估值上甩开所有已上市 AI 同行。

来源：[今日AI行业热点速览](https://m.sohu.com/a/1098939053_122550976/)

### 5. 英伟达开源 Cosmos 3 交互式世界模型

英伟达开放权重的世界仿真模型 Cosmos 3，可生成可交互的物理环境，显著降低具身智能与机器人训练的算力与授权门槛，物理 AI 基础设施进一步开源化。

来源：[今日AI行业热点速览](https://m.sohu.com/a/1098939053_122550976/) · [Google DeepMind](https://deepmind.google)

## 涨星最快项目

> 数据来源：GitHub Trending 周榜（2026 年 11 月第 1 周，统计截至 11 月 8 日）。[AI气道周榜分析](https://ai-kidou.jp/github-weekly-ranking-20261108/)

1. **pingdotgg/t3code** — 多 AI Agent 操作盘（agent harness control surface）：保留当前登录，在一个界面同时操作 Claude Code、Codex、Cursor、Grok Build 等。本周 +17,100 星（累计 51,398），是第二名约 1.8 倍。[GitHub](https://github.com/pingdotgg/t3code)

2. **mattpocock/skills** — Matt Pocock 从自己 `.agents` 目录整理出的工程师技能集（`/grill-me`、`/tdd` 等），小而可组合。本周 +9,664 星（累计 317,824），为全球星标最多的技能类仓库之一。[GitHub](https://github.com/mattpocock/skills)

3. **D4Vinci/Scrapling** — Python 网页抓取框架，覆盖单次抓取到全站爬取，内置 MCP 服务器与 Agent 技能、AutoThrottle 与 robots.txt 支持。本周 +8,712 星（累计 99,377）。[GitHub](https://github.com/D4Vinci/Scrapling)

4. **pbakaus/impeccable** — 给编码 Agent 提供设计词汇（polish/bolder/critique/audit）的技能，宣称 "No LLM, no API key"，两周连续进入 TOP10。本周 +7,623 星（累计 105,628）。[GitHub](https://github.com/pbakaus/impeccable)

5. **thedotmack/claude-mem** — Claude Code 跨会话记忆插件，用观察者 Agent 自动摘要工作，下一个会话从"记忆目录"开始。本周 +7,482 星（累计 114,549）。[GitHub](https://github.com/thedotmack/claude-mem)

## 新工具 & CLI

- **t3code** — 多 Agent 统一操作台，安装：`npx t3@latest`。本周 GitHub Trending 第一。（[GitHub](https://github.com/pingdotgg/t3code)）

- **Buoyant Kinference** — Apache 2.0 开源推理控制平面，为 vLLM on Kubernetes 提供声明式路由、KV-cache 感知负载均衡与多租户指标，自测将中位 TTFT 降低 95%。（[MarkTechPost](https://www.marktechpost.com/category/technology/ai-shorts/page/191/)）

- **Ripple-65B Preview** — Ricursive Intelligence 首个开源权重模型：65B 稠密 Transformer、12T token 预训练、1M 上下文，主打 Agentic Coding，11 月 4 日发布。（[AI/TLDR](https://ai-tldr.dev/models/ripple-65b-preview/)）

- **Scrapling** — Python 抓取框架，自带 MCP 服务器，`pip install scrapling`。（[GitHub](https://github.com/D4Vinci/Scrapling)）

- **DeepSeek Harness（dsh）** — DeepSeek 官方开源 Agent harness，MIT 许可，提供 Web UI、桌面端、CLI 与 SDK，支持插件架构与第三方模型提供商。（[aicoolies](https://aicoolies.com/use-cases/terminal-agents)）

- **OpenAI Agents SDK v0.24.0** — 10 月 15 日发布的新版本，持续扩展多智能体工作流能力。（[AgentUpdate](https://agentupdate.ai/releases/openai-agents-sdk)）

## 编程方式

- **Agent 编程成为 2026 年开发者主流** — GitHub Octoverse 报告显示：开发者的第一动作越来越多是"指挥 Agent"，审查成为塑造产出结果的关键环节；9 月已有 61% 的 Copilot 用户同时使用多个模型，并跨通用、深度推理与轻量模型分配任务。（[GitHub Blog](https://github.blog/news-insights/octoverse/octoverse-commits-pushes-reach-new-highs-in-2026-as-developers-build-with-agents/)）

- **小技能对抗"大框架接管"** — mattpocock/skills 明确反对 GSD、Spec-Kit 等"接管控制权"的大体系，主张把 AI 当问话对象（`/grill-me`）、由人保留判断轴；本周周榜多款工具（t3code、superpowers、hallmark）同样在设计上"把决策留给人类"。（[AI气道周榜分析](https://ai-kidou.jp/github-weekly-ranking-20261108/)）

- **设计语言进入 Agent 技能** — impeccable 等技能为编码 Agent 提供"polish/bolder/critique"等设计词汇，让 AI 产出在风格层面对齐人类审美，成为本周最热的一类 Skill 生态项目。（[GitHub](https://github.com/pbakaus/impeccable)）
