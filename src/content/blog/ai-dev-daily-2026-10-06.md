## 今日要闻

### OpenAI DevDay 2026 收官：GPT-6.1 Sol 发布，Dots 定位 AI 下一个核心入口

OpenAI 开发者大会一口气发布 20 多项新产品，正式推出 GPT-6.1 Sol——GPT-6 Sol 的重大升级，在智能体编程、计算机使用与专业工作方面表现出色，以仅约为 Astra 标准输入/输出 Token 价格五分之一的花费提供接近 Astra 的智能水平，现已面向所有 API、Plus、Pro、Business、Enterprise 计划开放，Ultrafast 版本即将到来。高管 Tibo 将新发布的 Dots 定位为 AI 的下一个核心入口，并透露 ChatGPT Work 与 Chat 将合并、Dots 能力将内置至覆盖 12 亿用户的 ChatGPT；他还确认内部已有 "6.1 Astra" 模型但选择暂不发布。

## 新工具 & CLI

- **GitHub Copilot CLI "Rubber Duck"（实验模式）**：引入来自不同 AI 家族的第二个模型作为独立审查者，在关键节点评估 Agent 的计划与产出，避免单一模型家族的系统性盲区。[GitHub Blog](https://github.blog/ai-and-ml/github-copilot/github-copilot-cli-combines-model-families-for-a-second-opinion/)
- **Project HydraFusion（GitHub 研究预览）**：面向 GitHub Copilot 的多模型编排方案，通过多个模型协同达到前沿质量。[GitHub Blog](https://github.blog/ai-and-ml/github-copilot/project-hydrafusion-frontier-quality-via-multi-model-orchestration/)
- **DeepSeek Harness**：开源的 Agent Harness 框架，模型、工具、技能、会话、存储、调度等一切能力皆可插件化重组。[deepseek.com/harness](https://deepseek.com/harness/en/)
- **LVTD-LLC/nitpick**：Rust 编写的 AI 代码审查 CLI，将 diff + 仓库上下文发送至任意 OpenRouter/本地模型获取结构化审查结果。[GitHub](https://github.com/LVTD-LLC/nitpick)（来源：[Awesome](https://awesome.lvtd.dev/)）
- **Claude Code /workflows 动态工作流**：让 Claude 动态编写编排脚本，在单次会话中并行调度几十到上百个子 Agent，先自我校验再交付。[Claude 官方博客](https://claude.com/blog/introducing-dynamic-workflows-in-claude-code)

## 编程方式

多模型编排成为编程新范式：GitHub Copilot CLI 的 Rubber Duck 让"第二个模型给 Agent 的第二意见"常态化，Project HydraFusion 则把多模型协同直接引入编码流程；Claude Code 的 dynamic workflows 将"数十上百个并行子 Agent"变成日常操作。与此同时，中文社区也在重新定义 AI 编程工具——"别再把它当补全工具了"：Copilot CLI 已 GA 并具备计划模式、Autopilot、后台委托等代理能力，AI 编程代理正在从"更聪明的补全"变成"可以协作的同事"。
