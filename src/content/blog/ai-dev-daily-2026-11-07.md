## 今日要闻

### 1. OpenAI 新一轮融资首批 110 亿美元到账，估值 1.25 万亿美元

11月7日消息，据知情人士透露，OpenAI 正在进行的新一轮融资已完成首批约 110 亿美元资金到账，本轮估值达 1.25 万亿美元，整体融资规模最高可达 200 亿美元，软银、红杉资本等参投，剩余资金预计未来几周到账。此前 OpenAI 曾计划融资至少 300 亿美元、估值 1.4 万亿美元，随后缩减目标。

来源：[新浪财经（格隆汇）](http://m.toutiao.com/group/7705195905670005282/) · [华尔街见闻](https://m.weibo.cn/detail/5362508316805723)

### 2. 腾讯混元 Hy4 正式开源，跻身最强开源模型行列

腾讯正式发布并开源混元 Hy4：770B 总参数、49B 激活参数，上下文超 100 万 Token，首次集成原生视觉能力与电脑操作能力，在编码、办公、科研等真实生产力任务上表现突出，官方称其已位居世界领先开源模型之列。

来源：[腾讯官网](https://www.tencent.com/tencent-launches-hy4-joining-the-ranks-of-the-worlds-leading-open-source-ai-models/) · [智源社区](https://hub.baai.ac.cn/?tag_id=1017)

### 3. 摩尔线程完成 Kimi K3.1 Pro 的 Day-0 适配

摩尔线程今日宣布，基于 AI 训推一体智算卡 MTT S5000 及 MUSA 软件栈，完成 Kimi K3.1 Pro 的 Day-0 适配，打通模型加载、服务启动及文本、图片基础推理链路。K3.1 Pro 是迄今能力最强的 3 万亿级参数模型，支持 100 万上下文。

来源：[IT之家（今日头条）](http://m.toutiao.com/group/7705070764638126592/)

### 4. Thinking Machines Lab 发布 Inkling 2 Small，下周开放权重

11月6日，前 OpenAI CTO 米拉·穆拉蒂创办的 Thinking Machines Lab 发布通用多模态模型 Inkling 2 Small，重点改善定制训练表现，支持开发者用自己的数据进一步训练。公司计划完成外部安全测试与红队测试后，于下周以 Apache 2.0 许可开放完整权重。

来源：[Thinking Machines Lab 官网](https://thinkingmachines.ai/news/inkling-2-small/) · [智东西](http://m.toutiao.com/group/7705035214006862376/)

### 5. OpenAI 发布 ChatGPT Images 2.6：支持一键生成 GIF

OpenAI 推出 ChatGPT Images 2.6 重大升级，生图速度提升 50%，首次支持一键生成 GIF、逐帧编辑与参考图生图；同日发布两款新 API 图像模型 Flare 与 Sunburst，支持 SVG 导出与 6 秒级生成。

来源：[MarkTechPost](https://www.marktechpost.com/2026/11/04/openai-gpt-image-2-6-flare-sunburst/)

## 编程方式

- **从"单 Agent"到"编排层"** — Amp Spaces 把 AI 项目经理作为编排者，自主拆分任务并协调多个 Agent 并行工作，与 DeepSeek dsh-superagent 的 Router-Worker 范式一脉相承，多 Agent 协作正在成为产品标配。（[IT之家](https://m.weibo.cn/detail/5362512843244897)）

- **Agent Skills 持续霸榜 GitHub Trending** — 周榜前五中 Impeccable、Hallmark、security-audit-skill 等四个均为面向编码 Agent 的 Skills/配套工具，"给 Agent 装技能包"仍是本周最受开发者关注的分发形态。（[DEV Community](https://dev.to/4sapi/github-weekly-agent-skills-sweep-top-3-de-ai-design-leads-4n91)）

- **用自有数据继续训练模型** — Inkling 2 Small 主打定制训练，支持开发者用私有数据继续训练或对其它模型微调，开源权重的"个人化微调"趋势进一步下沉。（[智东西](http://m.toutiao.com/group/7705035214006862376/)）

- **Agent 框架格局定型** — Microsoft Agent Framework 1.0 GA、LangGraph 1.0 与 Deep Agents、社区分支 AG2 1.0 三足鼎立，AutoGen 进入维护模式，框架选型焦点转向可观测性与协议互操作（MCP / A2A）。（[DEV Community](https://dev.to/avenotech/ai-agent-frameworks-compared-langgraph-vs-crewai-vs-autogen-2l2o) · [N-iX](https://www.n-ix.com/langgraph-vs-crewai-vs-autogen/)）
