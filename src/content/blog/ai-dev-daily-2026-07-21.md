## 今日要闻

### 1. Kimi 算力危机成焦点：国内 AI To C 首次因算力不足限流

7 月 19 日晚 Kimi 宣布暂停 C 端新用户订阅，K3 发布后 48 小时用户请求量超预估逼近集群极限。这是国内 AI To C 领域首次因算力不足被迫对 C 端用户"关门限流"，算力供给不足的问题从行业隐患变为公共事件，引发广泛关注。

来源：[广州科技局](http://kjj.gz.gov.cn/xydt/content/post_10909543.html) · [千龙网](https://tech.qianlong.com/2026/0721/8700484.shtml)

### 2. 科技日报：国产开源大模型参数规模冲击新高度

科技日报报道，国产开源大模型参数规模冲击新高度，Kimi K3 达 2.8 万亿参数，为全球最大开源模型。这一突破标志着国产开源模型在参数规模上首次领跑全球，从"追赶者"变为"领跑者"。

来源：[科技日报](http://www.stdaily.com/web/2026-07/21/content_550490.html)

### 3. 全球投资者质疑 AI 芯片过剩，中国 AI 公司却因需求过旺暂停新客户

当全球投资者质疑 AI 行业是否购买过多芯片时，中国 AI 公司却因需求过旺暂停新客户。这一对比形成鲜明反差：海外 AI 厂商面临"算力过剩"担忧，而中国 AI 厂商的算力供给远跟不上用户需求增长，供需矛盾成为行业核心议题。

来源：[中华网](https://news.china.com/socialgd/10000169/20260721/49625093.html)

### 4. WAIC 2026 后续影响：AI 从"炫技"到"实干"，具身智能进厂入户

WAIC 2026 落幕后，产业落地路径日益明确：AI 从"炫技"走向"实干"，具身智能开始"进厂入户"。从人形机器人产线应用到智能体手机，AI 进入物理世界的趋势在 WAIC 上得到集中验证。

来源：[央广网](http://www.cnr.cn/mspd/zhsh/20260729/t20260729_527735844.shtml)

### 5. 大模型之家 7 月热力榜：中国大模型把主场搬到世界舞台

大模型之家 7 月热力榜显示，WAIC 2026 所在的 7 月，中国大模型把主场搬到世界舞台。从 Kimi K3 登顶 Arena 到苹果牵手阿里千问，国产大模型在国际竞争中的角色从"参与者"转变为"定义者"。

来源：[澎湃新闻](https://m.thepaper.cn/newsDetail_forward_33711968)

## 涨星最快项目

### 1. mattpocock/skills — 社区最受关注的 Claude Code Skills 目录

7 月 GitHub AI 项目 Top20 出炉，Skills 生态彻底爆发。Matt Pocock 的工程级 Skills 仓库作为社区最受关注的 Claude Code Skills 目录，Star 数已逼近 48,000+。它将代理重构、测试、代码风格检查等实践沉淀为可复用的 Agent Skill，代表了"Skill 即工具"范式的成熟。

GitHub：[mattpocock/skills](https://github.com/mattpocock/skills) · 来源：[agentconn](https://agentconn.com/agents/mattpocock-skills/)

### 2. Nutlope/hallmark — 反 AI 味设计检测技能

hallmark 在 7 月持续登上 GitHub Trending，Star 数已突破 16,000。项目为 Claude Code、Cursor、Codex 提供 57 道"AI 味"检测关卡，成为 Skills 生态中最具代表性的设计类技能项目，"去 AI 味"需求随 AI 编程工具普及而持续走高。

GitHub：[Nutlope/hallmark](https://github.com/Nutlope/hallmark) · 来源：[open-repo](https://www.open-repo.com/)

### 3. emilkowalski/skills — 面向设计工程师的 Skills

前 Vercel / Linear 设计师的 Skills 仓库在 7 月涨星热榜中持续上升。项目将设计工程经验编码为 AI 可执行技能指令，核心 `improve-animations` 技能按八大维度审计动画。Skills 生态、Agent 基础设施和 MCP 生态在 7 月同时爆发。

GitHub：[emilkowalski/skills](https://github.com/emilkowalski/skills) · 来源：[头条](http://m.toutiao.com/group/7665602673865736745/)

## 编程方式

### Skills 生态彻底爆发，Agent 基础设施全面爆发

7 月 GitHub AI 项目 Top20 出炉，传递出最清晰的信号：Skills 生态彻底爆发、Agent 基础设施全面爆发、MCP 生态一夜成型。GitHub Trending 前 15 名中有 8 席是 AI Agent 项目，Claude Code 的 Skills 生态已有 1400+ 个技能包。Skills+Radio+Memory 正在成为 Agent 时代的"水电煤"——开发者不再逐行写代码，而是定义可复用技能，让 Agent 调度这些技能完成工作。来源：[头条](http://m.toutiao.com/group/7665602673865736745/) · [CSDN](https://blog.csdn.net/DQQzero/article/details/163444847)

### 算力供需矛盾重塑 AI 编程依赖结构

Kimi K3 发布 48 小时即因算力不足暂停订阅，而全球投资者却在质疑 AI 行业是否"买太多芯片"。这一矛盾正在重塑开发者的工具选择逻辑：过度依赖单一厂商云端算力存在产能风险，AirLLM 等本地推理工具的走红正是对这一风险的回应。AI 编程正从"all-in 云端大模型"走向"云端 + 本地"的混合架构。来源：[千龙网](https://tech.qianlong.com/2026/0721/8700484.shtml) · [中华网](https://news.china.com/socialgd/10000169/20260721/49625093.html)

## 总结

7 月的 AI 行业以一组鲜明对比收官：国产开源大模型 Kimi K3 以 2.8 万亿参数领跑全球、中国大模型把主场搬到世界舞台，却在算力供给上首次"关门限流"；而 GitHub 上 Skills 生态彻底爆发、MCP 一夜成型——Agent 编程正从单点工具走向标准化协作，算力供需矛盾则推动开发者重新思考云端与本地的混合架构。
