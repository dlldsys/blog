## 今日要闻

### 国产大模型 API 价格大洗牌：DeepSeek V4.1 Flash 暴涨 1400%，Kimi K3、GLM 5.3 大幅降价

10 月 4 日 API 价格数据显示，国产模型输入价格剧烈分化：DeepSeek V4.1 Flash 涨至 $0.30/百万 token（+1400%），Kimi K3 降至 $0.72（-73%），智谱 GLM 5.3 降至 $0.22（-84%），DeepSeek V4 Pro 0813 降至 $0.22（-67%）。厂商正通过激进重定价调整产品层级。

来源：[olud.ai](https://olud.ai/news/2026-10-04.html)

### Kimi K3 首次进入 OpenAI 企业付费结算体系

美国 AI 基础设施公司 Baseten 宣布，企业用户可在 OpenAI 编程工具 Codex 中使用 Kimi K3，调用费用直接计入企业已有的 OpenAI 采购承诺额度。这是中国开源模型首次进入 OpenAI 企业客户的主流付费结算通道。

来源：[钛媒体数智周报](http://m.toutiao.com/group/7692648387997958690/)

### Google 发布旗舰 Gemini 4 Argon，评分与 GPT-6 Astra 持平

Google 于 9 月 30 日发布 Gemini 4 Argon——自 Gemini 3.1 Pro 以来的首款旗舰。Artificial Analysis 给其 Intelligence Index 打出 52.6 分，与 GPT-6 Astra 持平，仅次于 Claude Opus 5.5 / Sonnet 5.5 / Fable 5.1，且是主流模型中测得的幻觉率最低者之一。

来源：[felloai](https://felloai.com/best-ai-models/) · [Nexchron](https://nexchron.com/news/ai-model-wave-opus-55-gemini-38-gpt6-sol-october-2026)

### 阿里通义霸榜 HuggingFace：7 个模型进前十，Qwen3-Omni 登顶

Hugging Face 最新开源模型排行中，阿里通义 7 个模型占据全球前十席位，新发布的 Qwen3-Omni 拿下榜首。

来源：[ai-damn](https://ai-damn.com/alibaba-s-tongyi-models-dominate-hugging-face-rankings-1759187810351)

## 编程方式

"循环工程"（Loop Engineering）成为新的编排范式：cobusgreyling/loop-engineering（11,330 星）提供用 AI 编码 Agent 设计提示与编排系统的实用模式与 CLI 工具（loop-audit、loop-init、loop-cost），思路受 Addy Osmani 与 Boris Cherny 启发。与此同时，Kimi Code 已形成 CLI / Web UI / 桌面客户端多形态，AI IDE 账号管理工具（cockpit-tools、quotio）热涨，说明开发者正同时管理多个编码 Agent 账号与配额——AI 编程正在从"单工具补全"走向"多 Agent 编排 + 工程化治理"。

来源：[GitHub](https://github.com/cobusgreyling/loop-engineering) · [IT之家](https://www.ithome.com/1/005/678.htm) · [GHTrending](https://www.ghtrending.com/ai-tools)
