## 涨星最快项目

### 1. langchain-ai/langchain — LLM 应用开发框架

LangChain 是最流行的 LLM 应用开发框架，提供链式调用、Agent 编排、RAG 管道和记忆管理等核心能力，几乎成为 LLM 应用开发的事实标准。目前约 95k 星。

GitHub：[langchain-ai/langchain](https://github.com/langchain-ai/langchain)

### 2. ggerganov/llama.cpp — 高性能本地 LLM 推理引擎

llama.cpp 是由 Georgi Gerganov 开发的高性能 C/C++ LLM 推理引擎，支持在消费级硬件上运行 Llama 等开源大模型，是本地推理生态的底层基石。目前约 75k 星。

GitHub：[ggerganov/llama.cpp](https://github.com/ggerganov/llama.cpp)

### 3. n8n-io/n8n — 开源工作流自动化平台

n8n 是一款开源的工作流自动化平台，近期深度集成 AI 能力，支持将 LLM 和 Agent 节点编入自动化流程，成为低代码 AI 工作流搭建的热门选择。目前约 75k 星。

GitHub：[n8n-io/n8n](https://github.com/n8n-io/n8n)

### 4. open-webui/open-webui — 本地 LLM Web 界面

Open WebUI 是一款为本地大模型提供 Web 交互界面的开源项目，常与 Ollama 配合使用，让用户在浏览器中即可使用本地 LLM，隐私友好且功能丰富。目前约 55k 星。

GitHub：[open-webui/open-webui](https://github.com/open-webui/open-webui)

### 5. browser-use/browser-use — AI 浏览器自动化工具

browser-use 让 AI Agent 能够自主操控浏览器，执行网页交互、数据抓取和表单填写等任务，是 Web Agent 领域的明星项目。目前约 55k 星。

GitHub：[browser-use/browser-use](https://github.com/browser-use/browser-use)

来源：[CSDN](https://blog.csdn.net/debug_fan/article/details/163221533)
