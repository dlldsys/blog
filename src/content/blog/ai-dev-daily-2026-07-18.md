## 今日要闻

### 1. WAIC 2026 第二日：MiniMax M3、Agent 原生操作系统、AI 智能体手机集中亮相

WAIC 2026 进入第二天，多项重磅产品亮相：MiniMax 发布 M3 多模态大模型，阶跃星辰展出 Agent 原生操作系统，近存计算 3D 芯片首次登场，全球首款 AI 智能体手机引发关注。展览从"炫技"转向"实干"，AI 进入物理世界的信号愈发明确。

来源：[21世纪经济报道](https://m.21jingji.com/article/20260718/herald/3b9f66a86786fea4a21b0caf4e96b8c6.html)

### 2. Kimi K3 发布数小时即登顶 Arena，中国模型首次登顶代码评测榜

Kimi K3 于 7 月 16 日晚发布后，短短数小时内登顶 AI 代码工具评测榜单 Arena，这是中国模型首次登顶该榜单。2.8 万亿参数的 MoE 架构加上原生视觉理解能力，使其在编码任务中表现出色，验证了国产开源大模型的竞争力。

来源：[广州科技局](http://kjj.gz.gov.cn/xydt/content/post_10909543.html)

### 3. 它石智航发布具身智能基座模型 AWE 3.5，WAIC 首秀

它石智航在 WAIC 2026 上首秀具身智能基座模型 AWE 3.5，主打物理 AI 泛化能力。该模型面向机器人场景，验证大模型在真实物理世界中的感知与决策能力。

来源：[新浪财经](https://cj.sina.cn/articles/view/7879923012/1d5ae154401903e602)

### 4. 面壁智能联合吉利发布具身智能体框架 RoboHarness

面壁智能与吉利人工智能中心联合发布具身智能体框架 RoboHarness，将 1.5B 参数 VLA（视觉-语言-动作）模型装进机器人。小参数模型端侧部署的路线，为具身智能落地提供了低成本方案。

来源：[澎湃新闻](https://m.thepaper.cn/newsDetail_forward_33711968)

### 5. 中国 AI 大模型加速"圈粉"海外，适配多元场景降本

中国 AI 大模型正加速拓展海外市场，通过适配多元场景和持续降本吸引海外用户。从开源模型的高性价比到本地化部署能力，国产大模型的国际影响力持续提升。

来源：[环球网](https://3w.huanqiu.com/a/de583b/4SPQTIUOzBn)

## 涨星最快项目

### 1. Nutlope/hallmark — 反 AI 味设计检测技能（持续增长）

延续昨日涨势，hallmark 持续登上 GitHub Trending。该项目为 Claude Code、Cursor、Codex 提供 57 道"AI 味"检测关卡，Star 数已突破 13,000，周增约 6,000 星。AI 编程工具越会写页面，开发者越需要一套方法判断页面是否"一眼假"。

GitHub：[Nutlope/hallmark](https://github.com/Nutlope/hallmark) · 来源：[腾讯云](https://cloud.tencent.com.cn/developer/article/2710178)

### 2. mattpocock/skills — 工程级 Claude Code Skills（持续增长）

Matt Pocock 的工程级 Skills 仓库继续高速增长，Star 数已达约 44,000+。作为社区最受关注的 Claude Code Skills 目录，它将代理重构、测试、代码风格检查等实践沉淀为可复用的 Agent Skill。

GitHub：[mattpocock/skills](https://github.com/mattpocock/skills) · 来源：[腾讯云](https://cloud.tencent.com/developer/article/2704288)

### 3. emilkowalski/skills — 面向设计工程师的 Skills（持续增长）

前 Vercel / Linear 设计师的 Skills 仓库持续登上涨星热榜，将设计工程经验编码为 AI 可执行技能指令，核心 `improve-animations` 技能按八大维度审计动画并生成修复方案。Agent 基础设施和 Skills 生态项目整体保持增长态势。

GitHub：[emilkowalski/skills](https://github.com/emilkowalski/skills) · 来源：[CSDN](https://blog.csdn.net/m0_68631449/article/details/162957318)

### 国内

- **Kimi K3（月之暗面）**：发布数小时即登顶 Arena 代码评测榜，中国模型首次登顶。2.8 万亿参数 MoE 架构 + 100 万 Token 上下文 + 原生视觉理解。[来源](http://kjj.gz.gov.cn/xydt/content/post_10909543.html)
- **MiniMax M3**：WAIC 2026 上发布多模态大模型 M3，进一步拓展多模态能力边界。[来源](https://m.21jingji.com/article/20260718/herald/3b9f66a86786fea4a21b0caf4e96b8c6.html)
- **面壁智能 RoboHarness**：与吉利联合发布具身智能体框架，1.5B 参数 VLA 模型装进机器人，走小参数端侧部署路线。[来源](https://m.thepaper.cn/newsDetail_forward_33711968)
- **它石智航 AWE 3.5**：WAIC 首秀具身智能基座模型，主打物理 AI 泛化能力。[来源](https://cj.sina.cn/articles/view/7879923012/1d5ae154401903e602)

### 国外

- **海外市场拓展**：中国 AI 大模型加速"圈粉"海外，凭借适配多元场景和持续降本吸引国际用户，开源模型性价比优势凸显。[来源](https://3w.huanqiu.com/a/de583b/4SPQTIUOzBn)
- **近存计算 3D 芯片**：WAIC 上亮相的近存计算 3D 芯片通过 3D 堆叠架构在成熟制程上实现高算力密度，为全球 AI 芯片提供新路线。[来源](https://m.21jingji.com/article/20260718/herald/3b9f66a86786fea4a21b0caf4e96b8c6.html)

## 编程方式

### Agent 从展台走向产线，具身智能进入工厂

WAIC 2026 第二日最具代表性的趋势是 AI Agent 从"展台演示"走向"产线应用"。面壁智能将 1.5B 参数 VLA 模型装进机器人、它石智航发布 AWE 3.5 具身智能基座模型，标志着大模型不再局限于软件场景，而是开始驱动物理世界的机器人执行任务。Agent 编程范式正从"写代码"延伸到"控制物理实体"。来源：[澎湃新闻](https://m.thepaper.cn/newsDetail_forward_33711968)

### Skills 生态持续爆发，Agent 基础设施成为热点

GitHub 涨星榜上 hallmark、mattpocock/skills、emilkowalski/skills 持续增长，印证了 Skills 生态的爆发趋势。开发者正将专业领域知识（设计规范、工程实践、安全测试）封装为 AI Agent 可调用的标准化技能，"Skill 即工具"的理念开始成型。来源：[CSDN](https://blog.csdn.net/m0_68631449/article/details/162957318)

WAIC 2026 第二日传递出清晰信号：Kimi K3 登顶 Arena 证明国产开源模型竞争力，而 Agent 正从展台走向产线——具身智能框架 RoboHarness 与基座模型 AWE 3.5 标志着 AI 编程范式从软件延伸到物理世界。
