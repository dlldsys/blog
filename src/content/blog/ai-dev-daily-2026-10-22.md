## 今日要闻

### Anthropic 推出 Claude Duet 研究预览：24 小时主动型 AI 智能体

当地时间 10 月 21 日，Anthropic 开放 Claude Duet 的研究预览（美国 Pro/Max 用户可排队申请）。与传统的"提问-回答"式交互不同，Duet 定位为主动工作的智能体：主动告诉你哪些事情需要关注、完成你交代的任务、即使你离开电脑也会继续干活，并在关键时刻征得你的确认才行动。Duet 由 Opus 5.5 驱动，可连接 6000+ 应用，面向小企业和专业人士，正式加入由 Meta Muse、OpenAI Dots 领衔的"全天候主动型 AI 助理"竞赛。

来源：[Introducing Claude Duet](https://claude.com/resources/articles/claude-duet) · [IT 之家/凤凰网](https://tech.ifeng.com/c/8xQ8PgLk5uB) · [新浪财经](http://m.toutiao.com/group/7699252873334506003/)

### MiniMax M3.1 Flash 正式发布：匿名"太空兔" Space Bunny 身份揭晓

10 月 19 日 MiniMax 正式发布 M3.1 Flash，并认领了国庆期间在 OpenRouter 匿名屠榜的神秘模型 Space Bunny（玉兔）——正是 M3.1 Flash 的早期版本，匿名运行期间累计处理超过 200 万亿 Token。正式版在智能体、编程、电脑操作与网络安全四方面实现代际提升，在 Agents' Last Exam（ALE）中以 29.6% 得分位居国产模型榜首；智能体任务综合使用成本较前代降低 70%，线上推理速度提升近 3 倍。

来源：[36氪](https://m.36kr.com/p/4034139912950921) · [艾瑞网](http://news.iresearch.cn/content/202610/570066.shtml) · [阿里云开发者社区](https://developer.aliyun.com/article/1772972)

## 编程方式

- **全天候主动型 Agent 成为新范式**：Anthropic Duet、Meta Muse、OpenAI Dots 三足鼎立，AI 从"等指令"转向"主动汇报 + 持续工作 + 关键确认"，编程与日常任务的处理边界正在被重画。[Claude 官方](https://claude.com/resources/articles/claude-duet)
- **Claude Code Projects 重设计：从文件夹到对话**：在项目里描述"需要完成什么"，Claude 自动拆分范围、协调并行线程、审查产出并组装结果，用户可从手机端随时介入，人离开后继续工作。[Claude Blog](https://claude.com/blog/projects-redesigned)
- **把编排写进代码**：GitHub Copilot 动态工作流让"多 Agent 流程"成为可版本控制、可复用的代码产物，Agent 协同从临时会话走向工程化资产。[GitHub Changelog](https://github.blog/changelog/2026-10-01-dynamic-workflows-in-copilot-cli-and-the-copilot-app/)
- **Codex CLI 实时协作体验**：中途重定向 + 并行只读工具的组合，让终端里的 Agent 协作更接近"实时结对编程"，迭代不再需要推倒重来。[AI/TLDR](https://ai-tldr.dev/releases/tool/)

## 总结

今日关键词是"主动性与基建"：Anthropic Claude Duet 让 24 小时主动型 Agent 走向主流，MiniMax 靠 M3.1 Flash 拿下国产 Agent 第一，DeepInfer 则把生产级推理底座焊死在涨星榜首——模型竞争正从"跑分"转向"主动服务能力 + 可部署的工程基建"。
