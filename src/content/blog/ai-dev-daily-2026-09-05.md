## 今日要闻

### 1. Meta 发布 Muse Spark 1.3：编码超 GPT-5.6，主打 Agent 成本战

9 月 2 日，Meta Superintelligence Labs 发布迄今最强模型 Muse Spark 1.3，这是 Spark 系列五个月内的第四次更新，官方称其为"模型性能最大的一次跃升"。头条是编码能力——官方直言超越 OpenAI 的 GPT-5.6 Sol，同时在长程 Agent 任务上比 1.2 版减少约 20% 的工具调用与 25% 的 token 消耗，主打"更少调用、更省 token"的实用性路线，发布当天即上线 Muse Code 与 Meta Model API。

来源：[AI News (GE)](https://ai-news.ge/en/article/meta-releases-muse-spark-1-3-coding-agents) · [Unite.AI](https://www.unite.ai/meta-launches-muse-spark-1-3-citing-gains-in-coding-and-agentic-tasks/) · [CSDN](https://blog.csdn.net/qq_34219119/article/details/164368246)

### 2. xAI 推出 Grok Bot 企业版：两周免费试用，AI"同事"进入企业

xAI 于 9 月 3 日宣布正式面向企业推出 Grok Bot，将其"teammates"（AI 同事）定位扩展至商业客户，提供两周免费试用。Grok Bot 此前于 8 月 11 日开启公测，作为持久化 AI Agent，可登录企业软件自主执行多步骤任务、跨应用协作，并在用户离开后继续工作。

来源：[Blockchain News](https://blockchainnews.azurewebsites.net/news/xai-grok-bot-enterprise-launch) · [Reworked](https://www.reworked.co/collaboration-productivity/xai-launches-grok-bot-ai-agents-in-beta/)

### 3. IFM 发布 K2 Horizon：六款全开源模型舰队，从 0.9B 到 375B

MBZUAI 旗下研究所 IFM 于 9 月 3 日发布 K2 Horizon，一次性推出六款模型（0.9B 至 375B-A23B），全部以 Apache-2.0 许可开放，除权重外还附带训练代码、数据混合配方、中间检查点与评估日志，被称为"业界最大的全开源模型舰队"，面向 Agent 场景构建。

来源：[AI-TLDR](https://ai-tldr.dev/releases/ifm-k2-horizon/) · [Neomanex](https://neomanex.com/news/ifm-k2-horizon-open-agentic-fleet-sep-2026) · [Moor Insights](https://moorinsightsstrategy.com/mbzuai-ifm-launches-6-k2-horizon-frontier-models-doubles-down-on-openness-analyst-insight/)

### 4. Google 发布 Gemini 3.8 Flash 与网络安全版 Flash Cyber

Google 于 9 月 2 日推出 Gemini 3.8 Flash，定位其最聪明的 Flash 模型，专为长期软件工程、自主代理与复杂企业工作流设计，面向开发者（Antigravity、AI Studio、Android Studio）、企业与消费者开放；同步推出受限访问的网络安全变体 Gemini 3.8 Flash Cyber。至 12 月 31 日前促销价为每百万输入 token 0.75 美元、输出 3.75 美元。

来源：[Unite.AI](https://www.unite.ai/google-launches-gemini-3-8-flash-with-cybersecurity-variant/) · [Gemini API Changelog](https://ai.google.dev/gemini-api/docs/changelog?hl=zh-tw)

### 5. 沙特推出阿拉伯语大模型 HUMAIN M3，底座是中国 MiniMax 开源模型

沙特人工智能公司 HUMAIN 于 9 月 3 日宣布推出首个阿拉伯语前沿大模型 HUMAIN M3，基于上海 AI 公司 MiniMax 的开源旗舰模型 MiniMax M3 构建。这标志着中国开源模型首次成为中东国家大模型的基座，被媒体评价为"不再只是卖 API"的出海新模式。

## 新工具 & CLI

### Google EnvHarness — 让静态 Agent 环境"活"起来

Google Cloud AI Research 等团队开源 EnvHarness，一个可编程层：通过 Setup（重置初始状态）、Rule（重塑交互规则）、Link（链式组合任务）等插件组件包裹静态环境，在不改动环境内部代码与验证器的前提下生成自适应训练世界，帮助 Agent 针对自身弱点持续进化。

来源：[GitHub](https://github.com/google-research/envharness) · [MarkTechPost](https://www.marktechpost.com/2026/08/30/google-ai-introduces-envharness-a-programmable-layer-that-turns-static-agent-environments-into-adaptive-training-worlds/) · [论文](https://arxiv.org/pdf/2608.19880)

## 编程方式

### 从"Agent 补全"到"Agent 同事"：多 Agent 协作与成本工程并行

本周两个信号把 AI 编程工作流推向深水区：一是 Claude Code 的 Agent Teams 模式让多个独立上下文窗口的 Agent 并行协作、共享任务列表、横向互通消息，接口先行（先定函数签名与 API 协议、再并行实现、最后集成）成为多 Agent 工程的主流范式；二是 Muse Spark 1.3 等模型把"工具调用次数与 token 消耗"作为显式优化目标——当模型智能趋同，"Agent 成本工程"成为新的竞争维度。与此同时，Grok Bot、Claude Cowork、ChatGPT Work 等"teammates"产品形态，让 AI 从代码助手进一步变成常驻团队协作者。

来源：[Claude Agent Teams 指南](https://claudefa.st/blog/guide/agents/agent-teams) · [CSDN · Agent Teams 使用指南](https://blog.csdn.net/Code_LT/article/details/159586665) · [Meta Muse Spark 1.3 分析](https://blog.csdn.net/qq_34219119/article/details/164368246)

## 总结

今日主线是"Agent 工程化进入深水区"：Meta 以成本效率（少工具调用、省 token）应战，xAI 把 Agent 卖进企业，Google 用 EnvHarness 让训练环境自适应进化，而 IFM 与 MiniMax 则分别以全开源舰队和中东出海基座证明开源路线的商业与生态价值——智能竞赛的下一程，比的是谁能把 Agent 做得更省、更可控、更能落地。
