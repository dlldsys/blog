## 今日要闻

### 1. WAIC 2026 今日开幕：展览面积首破 10 万平方米，1100+ 企业参展

2026 世界人工智能大会暨人工智能全球治理高级别会议今日在上海开幕，会期为 7 月 17 日至 20 日，主题为"智能伙伴 共创未来"。展览面积首次突破 10 万平方米，1100 余家企业参展、超 300 款产品全球首发，华为、阶跃星辰、努比亚等将集中展出超节点、智能体手机、Agent 操作系统等重磅产品。

来源：[大河基金](https://www.dayfund.com.cn/news/20260717fdca48BCZR.html) · [新浪财经](https://finance.sina.com.cn/wm/2026-07-17/doc-iniianxe7483503.shtml)

### 2. Kimi K3 发布：2.8 万亿参数，全球最大开源模型

7 月 16 日晚，月之暗面发布 Kimi K3，参数规模达 2.8 万亿，成为全球最大开源模型。采用 MoE 架构，896 个专家中激活 16 个，支持 100 万 Token 上下文窗口，并具备原生视觉理解能力。这是国产开源大模型在参数规模上的一次重要突破。

来源：[月之暗面官网](https://www.moonshot.cn/) · [东方财富](https://mgubatopic.eastmoney.com/list?id=11561)

### 3. 苹果 AI + 阿里千问合作确认：千问将集成至国行 Apple Intelligence

7 月 15 日完成生成式 AI 备案后，阿里通义千问将集成至国行 Apple Intelligence，覆盖 iOS、iPadOS、macOS 和 visionOS 全平台。这一合作意味着国产大模型正式进入苹果生态，为国行用户提供本地化 AI 体验。

来源：[中华网](https://news.china.com/socialgd/10000169/20260716/49612898.html) · [新浪财经](https://cj.sina.cn/articles/view/7879995964/1d5af323c068013k3o)

### 4. 国家发改委发布《人工智能合作发展行动计划》

国家发改委在 WAIC 2026 期间发布《人工智能合作发展行动计划》，提出推动算力普惠、开源共享、智能体互通等方向，为全球人工智能合作发展提供中国方案。

来源：[证券时报](https://stcn.com/article/detail/4025210.html)

### 5. 阶跃星辰发布全球首款大模型原生智能体手机

阶跃星辰在 WAIC 2026 上发布全球首款大模型原生智能体手机，并展出 StepAudio Voice Agent。这标志着大模型从云端走向端侧设备，AI 智能体开始进入消费级硬件产品。

来源：[21世纪经济报道](https://m.21jingji.com/article/20260718/herald/3b9f66a86786fea4a21b0caf4e96b8c6.html)

### 6. 华为 Atlas 950 超节点真机首次展出

华为 Atlas 950 超节点真机在 WAIC 2026 上首次展出，最大支持 8192 张昇腾 950DT 芯片直连，针对万亿级大模型训练场景设计。这是国产 AI 算力基础设施在超大规模集群方向的重要进展。

来源：[新浪财经](http://stock.finance.sina.com.cn/stock/go.php/vReport_Show/kind/search/rptid/837784019871/index.phtml)

## 涨星最快项目

### 1. Nutlope/hallmark — 反 AI 味设计检测技能

由 Together AI 的 Hassan El Mghari 开发的开源设计技能（design skill），专为 Claude Code、Cursor 和 Codex 等 AI 编码助手打造，核心功能是检测并消除 AI 生成页面"一眼假"的模板化设计。项目采用 MIT 协议，当前版本 v1.1.0，本周 Star 数已超过 12,200，周增约 5,800 星，登上 GitHub Trending。

GitHub：[Nutlope/hallmark](https://github.com/Nutlope/hallmark) · 来源：[dev.to](https://dev.to/max_quimby/hallmark-is-racing-to-12k-stars-for-a-reason-4jll)

### 2. mattpocock/skills — 工程级 Claude Code Skills 仓库

TypeScript 圈资深教育者、Total TypeScript 创始人 Matt Pocock 将自己每天用 Claude Code 做真实工程的实践沉淀成一整套 Agent Skill，覆盖代理重构、测试、代码风格检查和去 AI 味约定等场景，是社区最受关注的 Claude Code Skills 目录。本周 Star 数约 42,000+，持续高速增长。

GitHub：[mattpocock/skills](https://github.com/mattpocock/skills) · 来源：[腾讯云](https://cloud.tencent.com/developer/article/2704288)

### 3. emilkowalski/skills — 面向设计工程师的 Skills 集合

前 Vercel / Linear 设计师 emilkowalski 将多年设计工程经验编码为 AI 可执行的技能指令，核心机制 `improve-animations` 会扫描整个代码库中的动画，按缓动与时长、物理感、可中断性、性能、无障碍等八大维度审计并生成修复方案。本周持续登上 GitHub 涨星热榜。

GitHub：[emilkowalski/skills](https://github.com/emilkowalski/skills) · 来源：[头条](http://m.toutiao.com/group/7661823645311828521/)

### Skills 生态爆发，"Skill 即工具"成为新范式

本周 GitHub 涨星榜被 Claude Code Skills 生态占据——hallmark（反 AI 味设计）、mattpocock/skills（工程级技能包）、emilkowalski/skills（设计工程技能）同时登上热榜。这一趋势表明：AI 编程正从"写代码"走向"定义可复用技能"，开发者开始将专业经验编码为 AI 可执行的技能指令，Claude Code 的 Skills 生态已有 1400+ 个技能包且仍在快速增长。来源：[CSDN](https://blog.csdn.net/m0_68631449/article/details/162957318)

WAIC 2026 上阶跃星辰发布全球首款大模型原生智能体手机、华为展出 Atlas 950 超节点，标志着 AI 能力正从云端模型服务向端侧设备和超大规模训练基础设施两端延伸，Agent 不再只是聊天对象，而是开始嵌入物理世界的硬件入口。来源：[21世纪经济报道](https://m.21jingji.com/article/20260718/herald/3b9f66a86786fea4a21b0caf4e96b8c6.html)
