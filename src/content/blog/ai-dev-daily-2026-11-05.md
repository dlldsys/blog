## 今日要闻

### 1. 腾讯混元 Hy4 正式版发布：770B 参数，首次支持视觉理解与电脑操作

混元 Hy4 系列达到 770B 参数，首次引入视觉理解能力，并首次支持电脑操作（Computer Use），补齐了多模态与 Agent 执行能力两条线。点评认为 Hy4 真正的看点不止于参数规模，而是三条能力线同时补齐。

来源：[每日经济新闻·数智早参](http://m.toutiao.com/group/7704455300518085129/)

### 2. OpenAI 上线 Images 2.6：ChatGPT 原生生成并编辑 GIF 动图

据 The Verge 报道，OpenAI 推出新一代图像生成模型 Images 2.6，为 ChatGPT 增加原生 GIF 动画生成功能。用户输入文字描述或上传照片即可生成动态 GIF，还能在对话中调整播放速度、编辑单帧并分享作品。

来源：[凤凰网科技](https://original.ifeng.com/c/8xnRHOalLYD?ch=ttsearch)

### 3. DeepSeek 发布新架构，推动 AI Agent 走向更高自主性

DeepSeek 的 Harness 团队发文介绍其实验性"super agent"架构，目标让 AI Agent 摆脱被动等指令的模式，独立完成复杂任务，被视为中国模型厂商从聊天机器人走向自主执行系统的最新动作。

来源：[China Daily](https://global.chinadaily.com.cn/a/202611/03/WS6ae9399ae4b06d4aa0566a38.html)

### 4. SuperCLUE 11 月榜单：Gemini-4-Argon 总分第一，Kimi-K3.1-Pro 国内第一

SuperCLUE 发布 2026 年 11 月通用大模型测评榜单，共 19 个国内外模型参与，覆盖智能体编程、数理推理、超长上下文、精确指令遵循、幻觉控制五大任务。Gemini-4-Argon 拿下总分第一，Kimi-K3.1-Pro 位列国内模型首位。

来源：[快科技](https://m.weibo.cn/detail/5361787840235472)

### 5. 国行 Apple 智能接入通义千问

国行 Apple 智能与阿里巴巴达成合作，在 Siri、写作工具和视觉智能等体验中接入千问模型，覆盖文本与图像理解能力；IT之家实测发现问询结果会同步至千问 App，可语音播报、分享、重新生成。

## 编程方式

- **范式转移：从"写代码的人"到"指挥 AI 的人"**。2026 年开发者角色加速转变——Cursor 代表"项目内索引"范式、Claude Code 代表"推理优先"范式，Copilot 的毫秒级补全逐渐退居辅助位，AI 编程工具比拼的是对大型 codebase 的理解与编排能力。[腾讯云开发者社区](https://cloud.tencent.com/developer/article/2775511)
- **"删掉 IDE、干掉提示词、只写循环"**。Claude Code 之父推广 loop engineering：用 `/loop` 按间隔反复执行提示词、`/goal` 让 agent 一直干到条件为真，每轮由独立小模型判定完成度，编程从"写一次"变成"编排循环"。[36氪](https://m.36kr.com/p/3863483770606849)
- **GitHub Trending 被 agent Skills 霸榜**。11 月 2 日周榜 16 个项目中 13 个是为 Claude Code、Codex、Cursor 等编码 agent 打造的 Skills/插件/配套工具，前三名全是 Skills；Impeccable 以"反 AI 味"设计规则集单周涨约 1.2 万星。[DEV Community](https://dev.to/4sapi/github-weekly-agent-skills-sweep-top-3-de-ai-design-leads-4n91)
- **Anthropic《2026 Agentic Coding 趋势报告》**：八条趋势收敛于同一主题——软件开发正从"写代码"转向"编排 agent 写代码"，同时保留人类判断、监督与协作以保证质量。[Anthropic 报告](https://resources.anthropic.com/hubfs/2026%20Agentic%20Coding%20Trends%20Report.pdf)

今日趋势一句话：Agent 能力成为大模型竞争主轴——腾讯混元首次支持电脑操作、DeepSeek 发力自主 Agent 架构、GitHub Trending 被 coding agent 的 Skills 霸榜，开发者正加速从"写代码的人"变成"编排 Agent 循环的人"。
