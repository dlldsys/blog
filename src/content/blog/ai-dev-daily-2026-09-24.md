## 今日要闻

### 1. 千问发布 Qwen-Audio-3.1 系列语音大模型

9 月 23 日，千问正式发布 Qwen-Audio-3.1 系列语音大模型，对语音识别（ASR）、语音合成（TTS）与实时语音交互（Realtime）三大核心模型全面进化，并推出全新音频创作模型 Qwen-Audio-3.1-TTS-Next 与音频理解模型 Qwen-Audio-3.1-ASR-Next。

来源：[腾讯新闻](https://news.qq.com/rain/a/20260924A03EMV00)

### 2. 谷歌推出 Gemini 3.8 Flash TTS 与 Flash-Lite TTS 文本转语音模型

9 月 23 日，谷歌发布两款 TTS 模型：Gemini 3.8 Flash TTS 面向深度创意与角色设计、支持自然语言生成定制语音；Flash-Lite TTS 侧重高性价比大规模应用。二者均支持 100 多种语言，具备语音复制、混音与双声音编排能力，已上线 Google AI Studio 与 Gemini API。

来源：[DoNews](https://www.donews.com/newsflash/index)

### 3. 阿里云与基元律动签署战略合作协议

9 月 23 日，基元律动与阿里云签署战略合作协议，围绕 Qwen 系列模型协同优化、云计算基础设施及 MaaS 供应、市场生态建设展开合作，并将围绕典型 Agent 场景开展测试与评测。

来源：[每日经济新闻](http://m.toutiao.com/group/7688869684652917302/)

### 4. 智谱 GLM-5.3-Flash 日调用量 4.36 万亿 Token，登顶 OpenRouter 平台第一

据 OpenRouter 最新日榜数据（9 月 22 日），智谱 AI 旗下 GLM-5.3-Flash 当日调用量达 4.36 万亿 Token，较上一统计周期增长 73%，位列平台模型调用量第一；GLM-5.3 以 5240 亿 Token 位居第九。

来源：[财联社](http://m.toutiao.com/group/7688722663321960979/)

### 5. 云栖大会开幕：阿里公布 Qwen4 与下代视频模型均在训练中

9 月 22 日 2026 杭州·云栖大会开幕，主题"智以致用"。阿里巴巴公布大模型最新进展：基于下一代 Qwen4 架构的先导预览版 Qwen3.8-Flash-Next 已开源，Qwen4 与下一代视频模型均已在训练中。

来源：[新浪科技](https://finance.sina.com.cn/tech/roll/2026-09-22/doc-inissitm5734586.shtml)｜[浙江日报](http://m.toutiao.com/group/7688657494717088275/)

## 编程方式

AI 编程与智能体开发正从"单模型调用"走向"平台化 + 舰队化"：云厂商集体下场做托管 Agent 基础设施——阿里云千问 Agent Studio 提供 24 小时托管运行与 One Key MCP 生态接入，AWS AgentCore 与 Microsoft Agent Framework（Agent Harness / Hosted Agents / CodeAct）则把编排、状态与工具执行固化为平台能力；开源侧 stablyai/orca 继续放大"多 Agent 舰队"并行模式，而 vastsa/PI-Desktop 等本地桌面 agent 把整套 harness 搬进开发者本机，配合 cloudflare/security-audit-skill 把安全审计也 Agent 化——"托管平台 + 本地桌面 + 开源舰队"三层并行成为当前 AI 开发落地的主流路径。

今日趋势一句话：云栖大会与国内外密集发布把 9 月下旬推向"平台化 + 价格战"——千问以 Qwen-Audio-3.1 补全语音、智谱以 4.36 万亿 Token 拿下 OpenRouter 日调用量第一、OpenAI 与 Anthropic 同日降价上新，同时托管 Agent 平台（千问 Agent Studio / AWS AgentCore / MS Agent Framework）与多 Agent 舰队工具正重塑开发者的编程方式。
