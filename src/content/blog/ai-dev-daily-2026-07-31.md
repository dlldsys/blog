## 今日要闻

### 1. DeepSeek V4 Flash 正式版 API 公测上线

模型编号 DeepSeek-V4-Flash-0731，总参 284B 激活 13B，MoE 架构，原生支持百万超长上下文。模型结构与参数量同预览版完全一致，仅通过后训练优化。Agent 能力全面反超自家旗舰 V4-Pro 预览版，多项基准超越智谱 GLM-5.2，原生支持 Responses API 格式针对 Codex 优化。

来源：[太平洋电脑网](https://g.pconline.com.cn/x/2179/21795549.html) · [新浪财经](http://finance.sina.cn/2026-07-31/detail-inikstff0948523.d.html) · [ModelScope](https://modelscope.cn/models/deepseek-ai/DeepSeek-V4-Flash-0731)

### 2. MiniMax 发布新一代多模态生成模型 H3

从"特化任务模型"迈向"通用多模态智能"新范式，支持 2K 分辨率，采用 Contextual Omni Representation、H3-VAE、H3-Omni Transformer 等技术，8 月 3 日正式开源。

来源：[东方财富](https://finance.eastmoney.com/a/202607313828343432.html) · [MiniMax 官网](https://www.minimax.io/blog/minimax-h3) · [ModelScope](https://modelscope.cn/models/MiniMax/MiniMax-H3)

### 3. 特斯拉中国车机正式接入豆包大模型

向 Model 3/Y/S/X 全系推送更新，采用"豆包 + DeepSeek"双 AI 分工方案（豆包负责车控指令，DeepSeek 负责闲聊），0.5 秒听懂 18 种方言，外资车企首次在中国大规模引入本土第三方大模型。

来源：[澎湃新闻](https://m.thepaper.cn/newsDetail_forward_33707091) · [新浪](https://cj.sina.cn/articles/view/7879923871/1d5ae189f06801e8fa)

### 4. OpenAI GPT-5.6 降价中文媒体全面报道

Sam Altman 详细披露定价，GPT-5.6 系列三款模型（旗舰 Sol、主力 Terra、入门 Luna）降价，距公开发布仅约三周，模型商品化趋势加速。
